A modern WSL instance management tool

2026/01/20
Categories: Rust
Tags: Slint GUI

WSL Dashboard is a modern, high-performance, and lightweight WSL (Windows Subsystem for Linux) instance management panel built based on Rust and Slint, providing users with an advanced native experience.

When using it, users can easily manage existing distributions, create new instances, backup and restore data, migrate storage locations, and monitor WSL status and storage usage in real-time.

Aura Factory Development Manual

2025/12/25
Categories: Rust
Tags: Slint GUI

Aura Factory is a free and open-source desktop audio/video conversion tool developed based on the Rust language. It uses the modern GUI framework Slint to build the user interface and leverages FFmpeg as the underlying audio/video processing engine.

Aura Factory demonstrates the complete technology stack for modern Rust desktop application development, combining a high-performance system programming language with a modern GUI framework.
